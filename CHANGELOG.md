## [1.0.0] - 2026-11-18

### Added

- Four GPIO demos: blink an LED, toggle it with a button, switch it from an HC-SR04 distance sensor and control it from a phone.
- `scripts/hello.sh` from the terminal demo.
- Guides for setup, wiring (with a diagram), Linux commands and troubleshooting.
- Unit tests with gpiozero mock pins, and CI that runs Ruff, mypy, pytest and ShellCheck.
